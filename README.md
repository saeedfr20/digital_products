# Digital Products

A Django backend project for managing digital products, users, and files.

---

## 📖 About

Digital Products is a backend application built with Django as part of my journey to learn backend development.

The project includes a custom user authentication system, user profile management, device management, and product management.

This project is currently under active development.

---

- Custom User Model
- User Profile
- Device Management

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/digital_products.git
```

Create virtual environment

```bash
python -m venv .venv
```

Activate virtual environment

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Run development server

```bash
python manage.py runserver
```
